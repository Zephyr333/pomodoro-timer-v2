# 番茄钟计时器（Windows 托盘版）

当前版本：v3.0.0。

一个轻量、常驻系统托盘的番茄钟工具，支持长番茄钟、短番茄钟、长短休息、微休息、正计时与自定义计时，并提供手动修正、按日记录和周月年统计热力图。

## 项目来源

本项目基于 [lutischan-ferenc/pomodoro-timer-v2](https://github.com/lutischan-ferenc/pomodoro-timer-v2) 开发。

## 已实现功能

- 托盘图标动态显示：运行中显示倒计时，停止时显示 ▶。
- 完全中文菜单与核心交互。
- 自由修改当前剩余时间（分钟）。
- 自由修改今日番茄钟计数。
- 短番茄钟默认 45 分钟；长番茄钟默认 90 分钟，时长可独立调整。
- 长番茄钟默认计作 2 个番茄钟，可在“调整”中修改；完成长番茄钟时会按该数量计入统计。
- 可分别选择默认番茄钟（长/短）和默认休息（长/短）。
- 完成番茄钟后按默认休息类型衔接，不再使用“每四个番茄钟进入一次长休息”的规则。
- 正计时是与自定义计时并列的独立模式：从 0 持续向上计时，每累计达到一个短番茄钟时长就自动计 1，达到 n 倍时累计计 n。
- 支持超时正计时：倒计时归零后正常结算，再从 `+00:00` 持续正计时，不额外计入番茄数。超时支持暂停，托盘左键一次直接进入下一阶段；所有超时状态禁止修改或增减时间。运行中修改超时开关供新会话使用，当前会话继续使用启动时捕获的规则。
- 托盘图标会根据位数自动缩小字号，三位数分钟不会被裁切。
- 可切换当前静止状态（长/短番茄钟、长/短休息、正计时、自定义），无需立即开始。
- 自定义计时器模式（不计入番茄钟统计）。
- 支持事务式导入：替换当前数据前自动创建完整备份，失败时自动恢复。
- 支持数据位置切换：便携模式、OneDrive、自定义目录；目标已有数据时会中止，避免覆盖。
- 每次完成番茄钟自动写入 `pomodoro_log.csv`。
- `pomodoro_log.csv` 超过阈值后会自动按月归档，降低长期文件膨胀风险。
- 一键打开应用内月历热力图窗口（不依赖浏览器）。
- 支持按月份查看，使用窗口顶部 `<` `>` 切换年月。
- 点击月历中的任意日期，可查看当日完成番茄钟数量。
- 支持一键回到本月；蓝框标记今天，红框标记当前选中日期。
- 颜色深浅按单日 16 次番茄钟上限分层映射（1-4 / 5-8 / 9-12 / 13-16，16+ 统一最深色）。
- 菜单内可直接配置：长/短番茄钟时长、长/短休息时长、默认模式、自定义时长、音效、开机启动。

## 使用说明

### 左键点击托盘图标

- 普通计时运行中：结束当前计时并进入下一待机状态；暂停中：恢复当前计时。
- 超时正计时（包括暂停后的超时）：一次点击直接进入下一阶段。
- 微休息到点等待：开始微休息；微休息运行中：结束并显示原番茄待机；微休息到期：开启超时则进入超时，否则显示原番茄待机。“开始”接回冻结时间。
- 规则：长/短番茄钟 -> 默认休息，长/短休息 -> 默认番茄钟，正计时结束 -> 默认休息，自定义 -> 自定义。
- 非计时中：按“当前静止状态”启动对应模式。

### 右键菜单

- 会话：开始、暂停或继续、结束
- 切换：长番茄钟/短番茄钟/短休息/长休息/正计时/自定义计时（运行中也可直接切换）
- 待机：长番茄钟/短番茄钟/短休息/长休息/正计时/自定义计时（任何状态下可重新准备，放弃原会话且不立即开始）
- （分隔线）
- 全屏：全部屏幕、退出全屏、直接勾选各块屏幕、显示模式、显示签名
- 预览：签名（首项）、番茄钟、休息、微休息、正计时、自定义、超时，以及恢复默认
- （分隔线）
- 调整：时长调整项后有分隔线；下方可设置长番茄钟番茄钟数、修改今日计数或清零
- 时长：长/短番茄钟时长、短休息、长休息、微休息间隔和时长、自定义、步进时间、弹窗自动折叠秒数
- 偏好：时钟音效、完成声音、完成后弹窗、微休息、番茄钟计数、超时正计时、开机启动，以及平铺显示的四个默认模式选项；没有三级菜单
- （分隔线）
- 存储：便携模式、OneDrive、自定义位置
- 备份：导入数据、导出数据、恢复默认
- （分隔线）
- 统计
- （分隔线）
- 退出

### 微休息

- 默认关闭，间隔 15 分钟、每次 1 分钟；在“偏好 → 微休息”开启，在“时长”中调整。仅长、短番茄触发，没有独立启动入口。
- 刻度从本轮开始时长向下排列：45/15 在剩余 30、15 分钟触发，50/15 在 35、20、5 分钟触发。原始正数刻度保留；仅被动超时延长新增的刻度要求剩余时间至少一个间隔，0 点直接完成番茄；番茄完成后的超时不触发。
- 40/15 原始触发两次；到点等待超时累计增加 20 分钟时新增一次，增加 35 分钟时新增两次（含边界）。全屏预览临时覆盖全部在线屏幕，退出后恢复原选屏。
- 手动修改当前真实时间保留原刻度；跳过或直接设到刻度不触发，也不补发。
- 到点尚未开始微休息时，开启超时便从当前番茄剩余值反向增加；关闭超时便停住。例如 30 分钟等待到 +32 分钟，本轮被动延长为 47 分钟，已触发刻度平移到 32，下一刻度为 17。
- 点击开始微休息后，主番茄冻结在真实剩余值；微休息独立倒计时。微休息的暂停、调时和超时均不影响主番茄。
- 微休息到期后，开启超时便从 0 正计时，关闭则停在 0；结束超时后显示原番茄待机，必须点击“开始”才继续，不自动切回。微休息不增加今日番茄数。
- 关闭或折叠提醒不推进阶段；全屏保持原有不弹提醒的规则，可通过右键控制或托盘操作推进。

### 统一模式、状态与承接

- 模式表示正在计时或准备开始的类型；状态为待机、运行、暂停。全屏、托盘提示和弹窗统一显示“模式名 · 状态”：待机后缀为“未开始”，暂停后缀为“已暂停”，运行时只显示模式名。
- 完成提醒显示当前模式与三字状态，不显示“已完成”；主画面不会长期保留上一段的 00:00。关闭超时时，到点直接显示下一段的模式和待机时间；开启超时则显示“超时正计时”。
- 所有超时中的“开始”直接启动下一段，“结束”停止超时并进入下一段待机，“暂停／继续”只控制当前超时。
- 微休息到点而未开启超时，显示微休息设定时长待机；主番茄时间仍保留。微休息到期或提前结束后，显示原番茄类型和冻结时间待机，不自动恢复。
- “开始”启动画面上的待机目标；接回原番茄使用冻结值，修改默认时长不会覆盖它。显式改选其他待机模式会放弃原会话并清理保留上下文；直接开始可接回冻结值；若再选择待机模式，则明确准备一段全新的默认计时。相同配置保留勾选并忽略重复点击，自定义位置可另选目录，相同目录不重复迁移。
- 所有待机状态只有开始可用，暂停和结束置灰；正常运行只有暂停和结束可用；暂停时可继续或结束；超时时开始、暂停／继续和结束均可用。
- 全屏模式／状态行有“·”时以分隔符中心对齐屏幕横向中心，两侧间距相同；没有分隔符时整行居中。全屏预览使用同一排版，时间和签名保持原规则。

### 操作、默认设置与当前会话

- 已选配置保持勾选但可点击，相同配置不重复写入或迁移。“待机 → 模式”属于重新准备：任何状态下选择都会按当前默认时长初始化，清理原会话与冻结值，不立即开始、不补记未完成番茄。
- 新会话开始时捕获微休息、超时和计数规则。运行中修改这些设置供新会话使用；暂停、恢复、超时及番茄中的微休息链路继续使用原规则。
- 默认模式仅影响自动承接，不覆盖手动选定的待机类型；冻结番茄使用原类型和冻结值。界面、声音、弹窗设置立即生效。
- 修改今日番茄数及清零随时可用，即使关闭自动计数也可手动修正。确认值成为当前今日总数，之后正常累加；不改变时间、不回滚正计时已处理阈值、不补计旧阈值。
- 备份、存储菜单随时可展开。导出和恢复默认可随时使用；导入及真实位置迁移仅在计时真正运行时禁用，暂停或待机后可用，保留当前模式、进度、冻结值及规则。
- 恢复默认只改设置，不重置当前计时或原规则。数据导入／迁移保留原事务备份和失败恢复，选择目录或确认过程中若已继续计时，会要求先暂停再操作。
- 当前真实时间仍只允许普通运行和暂停时调整；待机、超时及微休息等待阶段禁用。输入期间阶段变化时明确告知输入未应用，设置默认值不受阶段变化限制。

### 全屏模式

- 在 Windows 原生托盘按住番茄钟图标左键，拖到目标屏幕后松开，让该屏幕加入全屏；已有全屏保留，重复拖到同一屏不会退出。拖动仅改变显示，不启动或结束计时。
- 松手位置在 Windows 通知区域、隐藏图标面板或 DisplayFusion 托盘区域（含时钟、系统状态区及图标间隙）时忽略；托盘内排序、拖出后拖回也不会触发计时。普通左键点击保持原操作。
- 拖动中按 Esc 取消。显示器布局变化或来源失效时取消本次拖动；来源不明确时不执行全屏。
- 本机 Windows 原生托盘拖动已经实测正常；DisplayFusion 11.1.1 托盘图标无法拖出，中键操作也不可用，本版本不保证这两种入口在 DisplayFusion 上生效。请从 Windows 原生托盘操作，或使用右键菜单“全屏”选择屏幕；DisplayFusion 托盘区域仍参与落点忽略判定。
- 排查拖动问题时可用 `pomodoro-timer.exe --tray-drag-log` 启动，在程序目录生成 `tray-drag.log`，每次最多记录 1024 行托盘手势信息；正常启动不记录。DisplayFusion 的版本差异仍需实际拖动验证，隔离回归测试不能替代真实托盘验证。
- 中键点击托盘图标，或选择“全屏 → 全部屏幕”，让所有当前在线显示器进入黑底全屏。已有窗口保留，只补齐缺少的屏幕；重复操作不会退出。
- “全屏”菜单直接列出屏幕编号和分辨率，勾选表示该屏幕当前正在全屏，无需打开选择窗口。选择另一块屏幕会加入现有全屏，取消勾选仅移除该屏幕；取消最后一块时退出全屏。
- 中键点击托盘始终覆盖所有屏幕，不受之前逐屏选择影响。整体退出后清空屏幕勾选，选择只在本次全屏期间有效。
- 各块屏幕显示同一份时间，覆盖任务栏；支持横竖屏、不同缩放比例和显示器布局变化。断开屏幕只移除对应窗口，其余窗口继续；新接入或重新接入的屏幕不会自动加入，可再次勾选或中键点击托盘加入。
- 全屏下点击鼠标右键操作计时（等同于左键点击托盘图标，提示随实际动作显示“开始”“继续”或“结束”），并保持全屏不退出。鼠标左键只退出点击到的屏幕；鼠标中键或 Esc 退出所有全屏窗口；也可以选择“全屏 → 退出全屏”。
- “全屏 → 显示模式”控制模式、待机、暂停等文字；“全屏 → 显示签名”直接切换签名显示。两者独立控制，都关闭时时间绝对垂直居中。
- 平时光标与提示自动隐藏，移动鼠标时屏幕底部显示“左键：退出此屏　中键 / Esc：退出全部　右键：当前动作”以及“中键点击托盘：全部全屏    拖动托盘图标：目标屏幕全屏”，静止 1.5 秒后隐去；鼠标移出全屏区域或打开托盘菜单时保持光标可见，不误隐藏。
- 运行中显示 `MM:SS`，超时显示 `+MM:SS`；超过 99 分钟继续显示完整分钟，例如 `100:00`。
- 待机时显示待机目标和对应时间（新计时为预设值，恢复番茄为冻结值）；暂停时保留时间，显示“模式名 · 已暂停”。
- 到时开启超时正计时则继续显示超时时间；关闭超时则直接显示下一段的模式、待机时间和“待机”。重新进入全屏仍使用同一承接结果。
- 完成声音遵循原有设置，全屏期间不弹出独立完成通知。超时依然不计入番茄数。
- 不读取或调整显示器亮度，不隐藏其他程序窗口，不屏蔽系统快捷键。

### 预览设置

右键一级菜单“预览”集中管理签名内容与全屏文字配色，没有三级菜单：首项为“签名”，经分隔线后依次为各计时模式配色，末尾为“恢复默认”：

| 模式 | 默认颜色 | 说明 |
| --- | --- | --- |
| 签名 | `#C4B8A8` | 自定义多行文字与独立配色（首项） |
| 番茄钟 | `#7F8C98` | 专注倒计时（长、短番茄钟） |
| 休息 | `#829889` | 休息倒计时（长、短休息） |
| 微休息 | `#829889` | 独立微休息倒计时，可单独配置外观 |
| 正计时 | `#8C86A3` | 独立正计时 |
| 自定义 | `#A39182` | 自定义倒计时 |
| 超时 | `#C79A52` | 超时正计时 |

- **签名设置**：点击“预览 → 签名”，打开合并后的“签名”设置窗口（位于“预览”首项）：
  - 支持多行文本输入，Enter 换行，保留空行；最多 500 个 UTF-16 字符单位、6 行。
  - 同一窗口内配置签名颜色代码，提供“选色”按钮。
  - 局部黑底大字预览实时跟随输入的文字与选取的颜色；长内容可滚动查看，不缩小字号。
  - “全屏预览”同时以草稿文字和草稿颜色全屏展示；左键、中键或 Esc 一次结束全部预览，恢复原编辑窗口与屏幕覆盖。
  - 点击“确定”同时保存签名内容与颜色；“取消”丢弃全部草稿修改。
  - 即使“全屏 → 显示签名”处于关闭状态，也可以正常编辑与预览签名；保存不改变显示开关。
- **预览一致性**：预览当前模式时使用打开窗口时的真实类型、时间和状态；局部时间预览与全屏预览使用同一份示例快照。其他模式使用对应完整模式名及合法状态，超时没有“未开始”的示例。
- **模式颜色**：点击“番茄钟”等模式，打开单项颜色窗口，支持输入六位颜色代码（可省略 `#`）或点击“选色”；下方用大字预览时间，点击“全屏预览”可全屏查看效果。
- **恢复默认**：“恢复默认”直接重置全部七种默认配色（包括签名颜色 `#C4B8A8`），不修改签名文本与其他设置。暂停沿用所属模式颜色，所有倒计时进入超时后，时间与状态统一使用超时颜色；签名始终保留自己的颜色。背景始终为纯黑。

### 快捷控制

- 通过 控制 子菜单执行 开始当前状态/暂停/继续/结束；通过 开始 子菜单可直接切换目标计时模式。
- 从“继续”恢复后会立即退出暂停态并刷新托盘图标显示，不会残留暂停状态。
- 运行中关闭时钟音效会即时静音；重新开启时会即时恢复循环音效。
- 当前时间调整只在普通活动计时或暂停时可用；待机、所有超时，以及微休息的两个等待阶段置灰。正计时减小真实时间不会回滚已入账统计，也不会重复计数。
- 手动修改“今日番茄钟计数”会即时同步到“今日”月历统计，不需要等到第二天。
- 执行“番茄计数清零”同样会即时同步到“今日”月历统计。
- 完成弹窗支持自动折叠为右侧提醒条，不会长期占用右下角空间；点击可展开继续操作。
- 自动折叠秒数可在右键菜单 `时长 -> 弹窗自动折叠(秒)` 中自定义（0 表示不自动折叠）。
- 默认自动折叠为 10 秒，时钟音效默认关闭。
- 完成声音可独立开关，不受时钟音效开关影响。
- 正计时不会自动结束，需手动结束或切换；结束后进入默认休息。它位于“切换”和“待机”菜单中“自定义计时”的紧上方。

## 数据文件

- `pomodoro_settings.json`：应用配置与当前计数。
- 配置保存采用临时文件替换策略，降低异常中断导致配置损坏的风险。
- 配置写入失败时会显示错误，不会静默假装保存成功。
- `pomodoro_log.csv`：每日番茄钟完成日志。
- `pomodoro_adjustments.csv`：手动修正每日统计的增量记录（用于即时同步月历显示）。
- 自动归档后会继续读取月归档日志，热力图统计不会因归档而缺失历史数据。
- 无需浏览器报表文件，统计以应用内热力图窗口呈现。

## 编译

推荐直接运行自动构建与冒烟测试脚本；它会依次检测 MinGW、Zig 和 Visual Studio Build Tools：

```powershell
.\tools\build_and_smoke_test.ps1
```

已有实例运行时，可只构建，不打断当前计时：

```powershell
.\tools\build_and_smoke_test.ps1 -BuildOnly
```

全屏原生集成测试（需要 MSVC Build Tools）：

```powershell
.\tools\test_fullscreen.ps1
```

测试默认在不可见的隔离桌面运行，使用独立进程和 `tools/.fullscreen-test/` 内的数据，不切换当前桌面、不改动已安装实例、用户数据或注册表，并生成窗口截图及结果日志。加 `-Interactive` 可在当前桌面观察测试；加 `-Stress` 才会连续执行八次全屏开关。交互测试期间点击或 Esc 会正常退出全屏，可能中断覆盖断言。

手动使用 MinGW 编译：

```bash
\mingw32\bin\windres pomodoro-timer.rc -o pomodoro-timer_res.o
\mingw32\bin\gcc -ffunction-sections -fdata-sections -s -o pomodoro-timer.exe pomodoro-timer.c pomodoro-timer_res.o -mwindows -lwinmm -lshell32 -lole32 -lgdi32 -lcomdlg32 -Wl,--gc-sections -static-libgcc
```
