# 番茄钟回归清单（手工）

## 全屏模式与颜色
- 中键进入全屏，原有托盘左右键行为不变；右键“会话 → 全屏”也能进入，名称只有“全屏”两字。
- 一级菜单“颜色”紧接“操作”、位于“存储”之前，所有子菜单无第三级；五类颜色项目直接打开单项输入窗口。
- 全屏底部没有退出提示文字；画面默认显示时间和模式/状态，关闭“偏好 → 全屏显示文字”后仅保留时间且绝对垂直水平居中。
- 进入、退出全屏不改变计时、暂停和番茄计数；待机进入全屏不会自动开始。
- 所有显示器各有一个无边框黑色窗口，覆盖任务栏，数字分别居中；横竖屏、负坐标和混合 DPI 下无空隙、裁切或跨屏拉伸。
- 点击任意全屏窗口或按 Esc 退出所有窗口；退出后鼠标显示正常、没有残留窗口。
- 倒计时与独立正计时显示 MM:SS，只有超时带 +；100:00 和 +100:00 显示完整。
- 暂停时数字保持、附“已暂停”；待机显示预设时长及“未开始”。
- 到时开启超时则继续 +MM:SS；关闭超时则停在 00:00 并标明“已完成”，即使关闭完成弹窗也应如此。
- 全屏到时遵循原有声音设置，无重复结算、无独立通知遮挡；超时不增加番茄计数。
- 五类默认色准确；代码输入、大小写、可选 #、系统选色器、黑底预览、确定、取消、恢复默认均可用。
- 单项颜色窗口字体、按钮及间距与现有输入框一致；打开时选中代码，确定只改当前颜色，取消不改配置；菜单恢复默认只重置配色。
- 无效代码不能保存；旧配置缺少颜色字段、字段越界、临时文件/备份恢复时均有正确回退或保留。
- Tab 可遍历输入框和按钮；Enter 保存、Esc 取消颜色对话框。
- 实际插拔显示器、改变缩放、切换主屏后覆盖正确；此项需真机操作，模拟 WM_DISPLAYCHANGE 不能替代热插拔验收。
- 全屏前后硬件亮度不变；其他应用没有被隐藏，系统快捷键仍可用。
- 多次进入退出及退出软件后无窗口/GDI 资源残留。

自动化入口：`tools/test_fullscreen.ps1`。使用项目内隔离数据，不调用会改注册表的恢复测试脚本。

## 1. 启动与托盘
- 启动后仅有一个托盘图标。
- 再次启动会提示“程序已在运行”。
- 退出后图标消失，无残留进程。

## 2. 计时基本流程
- 左键：停止状态可启动，运行状态可停止。
- 右键“开始长番茄钟/短番茄钟/短休息/长休息”可正确启动。
- 短番茄钟默认 45 分钟，长番茄钟默认 90 分钟，两者可独立修改。
- 长番茄钟番茄钟数默认 2，完成后会按该数量计入统计。
- 完成番茄钟后进入选定的默认休息，不按每四次自动切换长休息。
- 运行中图标显示分钟；低于 60 秒显示秒。
- 托盘 Tooltip 风格全场景对齐：待机显示“点击开始[模式名]”，运行态显示“[模式名] MM:SS”，超时显示“超时正计时 +MM:SS”，暂停态末尾追加“ (已暂停)”。
- 倒计时归零后若开启“超时正计时”，无缝进入超时阶段，图标显示 +SS/+M，绝对不计入番茄数。
- 超时正计时模型与正计时一致：运行中可暂停与结束，结束或左键点击后流转至下一待机状态，并自动清理残留 Toast 弹窗。
- 完成圆点按 1、2、3、4、1 的顺序循环显示。
- 三位数分钟完整显示，不裁切最右侧数字。
- “切换”和“待机”中均有独立的“正计时”，并且紧挨着位于“自定义计时”上一格；“偏好”中没有普通正计时开关，但有“超时正计时”开关。
- “调整”菜单最底部为“长番茄钟番茄钟数”。
- 正计时从 0 向上运行，每达到 n 个短番茄钟时长，统计累计增加 n；不会自动结束。
- 手动结束正计时后，下一待机状态为默认休息。
- 长/短番茄钟、休息和自定义计时保持原有倒计时行为。

## 3. 可编辑能力
- 右键“修改当前剩余时间(分钟)”输入合法值后生效。
- 输入越界值被拦截并提示错误。
- 右键“修改今日番茄数”可设置并持久化。

## 4. 空闲状态、正计时与自定义计时
- 空闲状态可切换为长/短番茄钟、长/短休息、正计时或自定义，且无需立即开始。
- 运行或暂停时，“待机”菜单项不可用，不会误结束当前计时。
- “调整”菜单在时长调整项和番茄钟计数项之间显示分隔线。
- 自定义计时完成后不增加番茄计数。
- 自定义计时完成弹窗可继续开始自定义计时。

## 5. 统计热力图
- 完成番茄后生成/追加 `pomodoro_log.csv`。
- “统计”打开应用内月历热力图，不依赖浏览器或 HTML 文件。
- 热力图中的本月、本年、累计数据与日志一致。

## 6. 设置、菜单与持久化
- 默认番茄钟和默认休息选项直接平铺在“偏好”菜单，不存在三级菜单。
- 时长、倍数、音效、默认模式、全屏显示文字和开机启动可保存。
- 重启程序后设置与计数保持不变。
- 将数据目录设为不可写时，保存失败会显示明确错误。

## 7. 数据安全
- 数据位置目标已有番茄钟数据时，迁移会中止且不会覆盖。
- 迁移复制任一文件失败时会回滚目标，新旧数据位置不会分裂。
- 导入前会创建自动备份；导入失败时恢复原数据。
- `recovery_chain_fault_injection_test.ps1` 通过，并在结束后恢复注册表和原数据文件。
